# GRIDLIFE v0.4 開発・修繕状況

更新対象：38項目。**本書は正式な機能完成証明ではありません。** 実装済みの基礎機能と、今後必要な高度化を分けて記録します。

## 検証済みの改修

- レース指示の入口を `act()` に一本化し、旧レース結果計算ブロックと日次決算の追加ラッパーを撤去
- 周回処理：燃料・タイヤ4種・雨天グリップ・ピット給油・黄旗ペナルティ・ライバルの消耗を簡易計算
- セーブキー `gridlife_alpha_1` を継続し、3世代履歴・旧データ補完・JSON検証・復元操作を導入
- レース途中のリロード後は停止状態で再開できる構成
- フリー走行・予選、研究開発、部品市場、借入返済、職歴集計を追加
- 区画指定建設、曜日表示、地域イベント、自動発注・自動整備を追加
- モバイルCSS、低画質オプション、雨/赤旗表示、順位表更新、合成通知音を追加
- `tests/regression.js` と `tests/integration.js` をGitHub Actionsへ接続

## テスト

```bash
node tests/regression.js
node tests/integration.js
```

模擬ゲームロジックで実行したテスト：500レース完了、3,650日分の決算、低資金からの3,650日試験でいずれも数値の非有限化なし。旧形式セーブ、破損バックアップ復旧、2周終了後のセーブ再開、全8画面のHTML生成についても確認した。

**未確認：** GitHub Actionsの完了ステータス、PC/スマートフォンでの実操作、数年プレイ時の最適な経営難易度。実機が必要な項目は合格扱いにしない。
